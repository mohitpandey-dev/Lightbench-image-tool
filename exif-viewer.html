EXIF viewer

A full read-out of the Exif data stored in a photo: camera, lens, exposure settings, and GPS location if present.

How to use EXIF viewer

  1. Drop a photo onto the page.
  2. Read the camera, lens and exposure details that appear.
  3. Look for a GPS section to see whether the photo carries a location.
  4. Use the exif remover if you want to clear that data before sharing.

Why use this tool

Most photos from cameras and phones carry a hidden block of information called Exif data. It records the device, the date and time, the exposure settings and sometimes the exact place where the picture was taken. Viewing it helps photographers learn from their shots and helps everyone see what a file reveals before they share it.

Tips for best results

  • Photos from messaging apps and screenshots often have little or no Exif data, because the app removed it.
  • Check the GPS section first if privacy is your concern.
  • The date in Exif is set by the camera clock, so it can be wrong if the clock was never set.

Frequently asked questions

What is Exif data?

Exif stands for Exchangeable image file format. It is metadata a camera writes into the picture file along with the image itself.

Can Exif data be faked?

Yes. It can be edited, so treat it as a clue rather than proof.

Does viewing it change my photo?

No. The viewer only reads the file and never modifies it.
