Image metadata viewer

See what a photo is carrying with it: file details, camera information, and GPS location if it has one.

How to use Image metadata viewer

  1. Add a photo to the page.
  2. Review the file details such as type, size and dimensions.
  3. Scroll to the camera section for make, model and settings.
  4. Check whether a GPS location is listed.

Why use this tool

Every image file carries more than pixels. It has a type, a size, dimensions and often camera information and a location stamp. Seeing all of it in one place lets you confirm what you are about to share, check a file against an upload requirement, or work out where a picture came from.

Tips for best results

  • Compare the pixel dimensions here with the size a website asks for.
  • If a location is listed and you do not want it public, strip it with the exif remover.
  • Edited images may keep the name of the editing software in their metadata.

Frequently asked questions

What is the difference between this and the EXIF viewer?

The metadata viewer gives a broader summary of the file, including its basic details. The EXIF viewer focuses on the camera data.

Why is some information missing?

Social apps and screenshot tools often remove metadata. Missing fields simply were not stored in that file.

Is the photo uploaded?

No. The file is read locally in your browser.
