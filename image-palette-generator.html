Image palette generator

Pull the dominant colours out of a photo, ready to copy as hex codes or CSS variables.

How to use Image palette generator

  1. Drop in a photo.
  2. Wait while the dominant colours are extracted.
  3. Click a swatch to copy its hex code.
  4. Copy the whole palette as CSS variables if you need them in code.

Why use this tool

A good palette can be hiding inside a photograph. Extracting its main colours gives you a set that already works together, which is a quick way to build a colour scheme for a website, slide deck or poster that matches a picture.

Tips for best results

  • Photos with a clear mood, such as a sunset or a forest, give the most useful palettes.
  • Pick a few colours and test the text contrast on them before using them for words.
  • Resize very large photos first if the page feels slow.

Frequently asked questions

How are the colours chosen?

The tool groups similar pixels together and shows the colours that cover the largest parts of the image.

Can I use the palette commercially?

The colour codes are just numbers. You are free to use them, but check the rights for the photo itself.

Does it work with logos?

Yes. A logo with flat colours gives a very clean palette.
