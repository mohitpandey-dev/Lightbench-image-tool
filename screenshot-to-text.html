Screenshot to text

Turn a screenshot into text you can copy and edit, such as an error message, a chat, or a line of code.

The first time you recognise text, your browser downloads a small recognition engine and language file, so it needs an internet connection. After that it is cached for next time.

For code or logs, try "Single block of text" or "Single line" below if the automatic layout mixes up the line order.

How to use Screenshot to text

  1. Add a screenshot or paste one.
  2. Let the tool read the text.
  3. Check the result against the image.
  4. Copy the text for your document, chat or code.

Why use this tool

Error messages, chat threads, code snippets and web pages are often only available as a screenshot. Pulling the text out lets you search for an error, paste a command, or quote a message without retyping a thing. Screenshots are the easiest input for text recognition, because the letters are clean and perfectly straight.

Tips for best results

  • Zoom in before you take the screenshot so the text is large.
  • Dark mode works, but plain black text on white is read most reliably.
  • Check code carefully. Symbols such as brackets and quotes are easy to misread.

Frequently asked questions

Why does some text come out wrong?

Small or compressed screenshots lose detail. Retake it larger, or crop closer to the text.

Can I use it on a phone screenshot?

Yes. Choose the file from your gallery.

Is the screenshot uploaded?

No. Everything is processed in your browser.
